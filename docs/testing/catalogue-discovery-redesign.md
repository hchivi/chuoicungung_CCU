# Catalogue discovery redesign · 2026-10-07

Scope: `/catalogue` discovery menu and listing cards. Shared navigation, hero, data, detail routes, viewer/participation modals and upcoming-publication sections remain unchanged.

## Design

Hallmark informed the publication-library treatment: portrait book covers using existing record images, pale paper/green display surfaces, edition/date/format beside each cover, full titles and a clear primary detail action. No decorative icons, coloured badge collection or animated card effects were added. Existing Space Grotesk/Poppins typography and CCU palette are retained through scoped tokens in `tokens.css`.

Desktop has an underlined publication-type index and a complete bordered filter panel. Mobile uses a labelled native type selector and an expandable secondary-filter area. Record descriptions, linked programme and publisher remain available in each card's native “Thông tin ấn phẩm” disclosure. Quick digital view and PDF callbacks retain their existing owners.
